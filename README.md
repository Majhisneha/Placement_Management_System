PLACEMENT MANAGEMENT SYSTEM

## Project Description

This project is my **Placement Management System**. It demonstrates:

- Backend API development in **Java** using Spring Boot
- CRUD operations (Create, Read, Update, Delete) for managing student data
- Database connectivity using **MySQL**
- API testing using **Postman**
- Project structure includes `src/` for code, `pom.xml` for dependencies, and Maven wrapper for build management

## Key Features

- **REST API Endpoints**:
  - `GET /students` → Fetch all students
  - `GET /students/{id}` → Fetch a student by ID
  - `POST /students` → Add a new student
  - `PUT /students/{id}` → Update student details
  - `DELETE /students/{id}` → Delete a student

- **Technologies Used**:
  - Java, Spring Boot, Maven
  - MySQL for database
  - Postman for testing

## How to Run

1. Clone the repository
2. Open in your IDE (Eclipse/IntelliJ/Replit)
3. Run `PlacementsCollegeApplication.java` as a Java application
4. Make sure MySQL database is running and credentials are correct in `application.properties`
5. Use Postman or any REST client to test API endpoints
